## 실제 시험에서 멈췄던 부분

- **ALB 검사:** 이미지 교체 중 대상이 아직 준비되지 않아 검증이 중단됐고, 정상 준비 후 같은 절차를 재개해 통과했습니다. 복원 중에는 Kubernetes 조회 오류 후 재확인에서 정상인 경우도 있었습니다. 조회 오류의 당시 원인을 확정한 것은 아닙니다.
- **CloudTrail 삭제:** 긴 인프라 삭제 도중 로그 객체가 늦게 도착해 마지막 로그 버킷이 남았습니다. 같은 삭제 절차를 재개해 비운 뒤 삭제했습니다.
- **빈 SQS 조회:** 큐를 모두 삭제했을 때 CLI의 빈 출력을 JSON으로 읽다가 중단됐습니다. #12에서 명시적인 빈 목록 응답으로 수정했고 실제 최종 삭제·잔여 검사까지 통과했습니다.
- **승인 연동:** API 생성 검사 결과가 이전 CI 묶음에 붙는 문제가 있어 #8·#10에서 수정했습니다. #8만으로 해결 완료한 것으로 취급하지 않으며, #10 이후 native Actions 승인 검사와 보호된 병합을 확인했습니다.

**이번 자동 재시도 변경은 AWS를 실행하지 않고 모의 API·명령·시간으로 검증합니다.** 다음 실제 설치에서 준비 지연과 다음 전체 삭제에서 지연 로그를 만나더라도 제한된 범위만 자동 재시도하는지 추가 확인해야 합니다. 모든 설치·복원·삭제 오류의 자동 복구를 보장하지 않습니다. AWS 리소스 추가, 보존 중 NAT 제거, 다른 PC용 복구 방식, 학원 계정 전환은 이번 수정에 포함하지 않았습니다.
