# 검증 범위 · AWS 실행과 로컬 검사를 구분하기

main `cc040cf`를 기준으로 2026-11-04에 분석을 시작하고 11월 5일 문서·이미지 검증을 마쳤습니다. 이번 작업은 문서 변경이며 AWS 생성·변경·삭제 또는 실서비스 재시험을 하지 않았습니다.

## 근거의 종류

1. **현재 코드:** Terraform·활성 Kustomize·Actions·서비스 코드가 무엇을 선언하는지 확인합니다. 코드가 있다는 사실은 AWS에서 모든 장애를 시험했다는 뜻이 아닙니다.
2. **과거 AWS 실행:** 당시 저장한 조회 결과·워크플로·화면·사용자의 메일 수신 확인을 근거로 합니다. 사진의 날짜와 실습 구성이 다른 기록을 한 번의 실행으로 합치지 않습니다.
3. **로컬 검사:** 모의 API·상태 전이·회귀 검사·문서 정합성입니다. 실제 RDS·네트워크·SES 장애 시험을 대신하지 않습니다.

## 공개 근거와 비공개 원본

- 배포 소스·이미지 PR과 main의 release 선언은 [배포 이력](RELEASES.md)에서 추적합니다.
- [실행 근거 요약 JSON](validation/2026-11-evidence-summary.json)은 보관 원본에서 선택한 비민감 사실과 파일 SHA-256입니다. 새로운 AWS 조회 결과나 원본 전체를 공개한 파일은 아닙니다.
- 원본 `final-v3-result.json`, `rollback-result.json`, `rds-retake-result.json`, `nat-path-result.json`과 당시 캡처는 로컬 증거 보관본입니다. hash는 원본 식별용이며 그 자체로 제3자의 AWS 실행 인증을 의미하지 않습니다.
- state·복구 비밀값·전체 로그·이메일 본문은 공개하지 않습니다. 공개 저장소만으로 모든 콘솔 화면까지 재검증할 수 있다는 주장은 하지 않습니다.

## 삭제 결과와 현재 상태의 경계

당시 최종 삭제 감사에는 프로젝트 EKS·RDS·S3/state·스냅샷·SQS·CodeBuild 등 잔여 확인 결과가 있습니다. 도메인·DNS의 기본 레코드·기존 로그 등 보존 기준 자원은 따로 기록했습니다. 이는 **그 시점의 프로젝트 감사**이며, 지금 계정 전체에 과금 자원이 하나도 없다는 실시간 확인은 아닙니다.

## 아직 보장하지 않는 것

- NAT 자동 우회의 main 통합·운영 정책·장기 안정성
- 전체 AZ 중단, 다중 동시 장애, 데이터 무손실·연결 중단 0초
- 모든 서비스의 다중 파드·서비스 간 NetworkPolicy·mTLS
- 모든 주문 실패 창의 AWS 장애 주입 검증 또는 정확히 한 번 메일 전달
- 다른 계정으로의 무수정 이식, 팀 공용 복구 키 관리와 정기 DR

현재 구성과 설계상 경계는 [아키텍처](01-architecture.md), 설치·보존·완전 폐기는 [실행 가이드](15-one-command-lab.md)에서 확인합니다.
